1시작하기

SmartMeet은 학회·협회·동문회 등 회원 단체의 운영을 위한 통합 시스템입니다. 회원 명단·임원 관리·이벤트 운영·정관·조직도·게시판을 한 곳에서 처리할 수 있습니다.

주요 기능 한눈에 보기

기능설명
🏛 기관 홈기관 인사말·소개·정관·조직도를 노출하는 공식 홈페이지
👥 임원 명단 / 회원수첩역대 임원 기수별 관리 + 가입회원 연락처 디렉토리
📋 이벤트 (회의·행사)안건·출석·위임장·회의록·프레젠테이션까지 회의 운영 풀스택
🗓️ 일정 캘린더월별 캘린더 + 다일 일정 + 이벤트 자동 연동
📜 정관·조직도WYSIWYG 정관 편집기 + 드래그 조직도 + A4 인쇄
💬 게시판·공지공지사항·자유게시판·회원소식
📱 모바일 최적화햄버거 메뉴 + 시트 모달 + 반응형 캘린더
💡

권한 체계: 시스템 관리자(전체) / 기관 관리자(해당 기관) / 일반 회원(읽기 + 자기 글) 3단계로 나뉘어 있습니다. 기관 관리자는 사이드바를 통해 모든 관리 메뉴에 접근하고, 일반 회원은 상단 햄버거/탭 메뉴로 공개된 정보만 볼 수 있습니다.

2회원가입 · 로그인

회원가입 (이메일 인증 방식)

  1. 가입 정보 입력이메일·비밀번호·이름·전화번호 입력. 전화번호는 자동으로 010-1234-5678 형식으로 변환됩니다.
  2. 이메일 인증 메일 발송"회원가입" 클릭 시 입력한 이메일로 인증 링크가 발송됩니다.
  3. 인증 링크 클릭1시간 이내에 메일 안의 링크를 클릭하면 가입이 완료되며 자동 로그인 상태가 됩니다.

로그인 · 비밀번호 찾기

로그인 화면(/login) 에서:

  • 로그인: 이메일 + 비밀번호 입력
  • 아이디 찾기: 가입 시 등록한 이름 + 전화번호로 마스킹된 이메일 조회
  • 비밀번호 찾기: 이메일로 재설정 링크 발송 (1시간 유효)

초대코드로 기관 가입

이미 SmartMeet 계정이 있는 경우, 관리자가 발급한 초대코드를 입력해 기관에 가입할 수 있습니다.

  1. 사용자 메뉴 열기우측 상단 사용자 chip(이름) 클릭 → 드롭다운 메뉴
  2. "🎫 초대코드 입력" 선택코드 또는 초대 링크 전체 붙여넣기 (자동으로 토큰만 인식)
  3. 가입 확인기관 정보(로고·이름·설명) 미리보기 → 확인 시 즉시 가입 + 기관 홈으로 이동

3기관 관리

기관 목록

로그인 후 /dashboard로 자동 이동하며 본인이 가입한 기관들을 카드 또는 목록으로 볼 수 있습니다.

기관 홈

기관 진입 시 보이는 공식 홈페이지입니다. 다음 영역으로 구성됩니다:

  • Hero 영역: 메인 이미지 + 기관명 + 부제목
  • 슬로건 바: 강조 메시지 한 줄
  • 탑 네비게이션: 기관소개 / 임원진 / 회원수첩 / 커뮤니티 / 기관일정
  • 섹션별 콘텐츠: 인사말 · 정관 · 조직도 · 공지 · 일정 등
  • 푸터: 로고 + 기관명 + 주소·연락처 (편집 모달에서 표시 옵션 선택 가능)
💡

관리자만 보이는 편집 버튼: Hero "✏️ 메인 편집", 인사말 "수정", 푸터 "수정" 등은 기관 관리자에게만 표시됩니다. 일반 회원은 동일 화면에서 콘텐츠만 보게 됩니다.

기관 탈퇴

사용자 메뉴 → 🚪 기관 탈퇴하기 → 확인 모달 → 탈퇴 완료. 탈퇴 후엔 기관 공지·일정·게시판에 더 이상 접근할 수 없습니다. 기관 소유자는 탈퇴할 수 없습니다.

4임원 명단

역대 임원진(기수별)을 관리하는 페이지입니다. 회장·부회장·이사·감사 등 직책과 함께 기수별로 정리되며, 회원수첩의 직책 표시도 이 데이터를 참조합니다.

임원 추가 · 수정

  1. "+ 임원 추가" 클릭기수·순번·직책·이름·전화·이메일·전공·직장·사진 입력
  2. 저장해당 기수 탭에 표시되며 기수 탭이 처음 생성되면 자동으로 활성
  3. 수정/삭제각 행 우측 버튼으로 인라인 수정·삭제

엑셀 일괄 등록

임원 명단을 엑셀(.xlsx)로 한 번에 등록할 수 있습니다. 컬럼 형식:

컬럼내용필수 여부
기수예: 제 10 대필수
직책회장 / 이사 / 감사 등선택
이름홍길동필수
전화010-1234-5678 (자동 정규화)선택
이메일name@example.com선택
전공경영학선택
직장○○회사선택
⚠️

중복 검출: 미리보기 단계에서 같은 기수 + 동일 전화번호인 항목, 그리고 이미 DB에 있는 전화번호와 충돌하는 항목을 모두 표시합니다. 등록 직전에 행 단위로 제외 가능.

순서 변경 (드래그 앤 드롭)

각 행 좌측의 ⋮⋮ 핸들을 잡아 위/아래로 끌어 순번을 변경합니다. 핸들에서만 드래그가 시작되므로 행의 텍스트는 자유롭게 선택·복사 가능합니다.

5역대 회장

임원 명단에서 직책에 "회장"이 들어있고 "부회장"은 아닌 사람들만 자동 추출되어 표시됩니다. 우측 상단 🪪 카드 / 📋 목록 토글로 뷰 전환.

6회원수첩

기관에 가입한 회원 전체의 연락처·전공·직장 정보를 디렉토리 형태로 보여줍니다. 임원으로 등록되어 있으면 직책이 함께 표시됩니다 (예: 회장, 이사). 그렇지 않으면 권한(소유자/관리자/회원)이 fallback 으로 표시됩니다.

주요 기능

  • 🔍 검색: 이름·이메일·전화·전공·직장 (전화는 숫자만 비교 — 010-12 든 01012 든 동일 결과)
  • 🏷️ 필터: 전체 / 관리자 / 회원
  • 🪪 뷰 토글: 카드 / 테이블
  • 📥 엑셀 내보내기: 선택한 회원만 추출 (전화번호는 하이픈 형식으로)

가입회원 → 임원 가져오기

회원으로 가입한 사람을 임원 명단에 빠르게 추가합니다. 기관 관리자만 사용 가능. 검색 + 다중 선택 + 기수 지정 + 일괄 추가.

7일정 관리

캘린더 뷰

월별 그리드 캘린더로 모든 일정을 시각화합니다. 다일 일정은 셀과 셀을 잇는 막대로 표현됩니다.

목록 뷰 + 필터

다가오는 일정과 진행중인 일정을 카드 행 형태로 표시. 필터: 최근 10건 / 1개월 / 3개월 / 6개월 / 1년 / 전체. 모든 필터는 오늘 기준 ±N개월 윈도우로 과거 일정도 함께 보입니다.

💡

모바일 캘린더 — 날짜 탭: 좁은 화면에서 작은 이벤트 막대를 정확히 누르기 어렵기 때문에, 일자 셀이나 이벤트 막대를 탭하면 그 날짜의 모든 일정이 모달 리스트로 펼쳐집니다. 관리자에게는 "+ 일정 추가" 버튼도 함께 노출됩니다.

8이벤트 (회의 · 행사)

이사회·총회 같은 정식 회의와 일반 행사를 관리하는 핵심 모듈입니다. 안건·출석·위임장·회의록·프레젠테이션 모드를 모두 지원합니다.

이벤트 등록

관리자 사이드바 → 이벤트 관리 → "+ 새 이벤트 등록".

구분설명
이사회 / 총회의결 정족수·찬반 집계 등 정식 회의 기능 활성
일반안건 없이 단순 모임
행사초대장 링크로 외부 신청 받기 (자유 신청 → 자동 출석부 등록)

회의 목차 · 의안

회의 진행 순서를 정의하는 회의 목차(개회사·인사·보고·폐회 등)와, 정식 의결 대상인 의안(일반 / 예산·결산 / 선거)을 따로 관리합니다.

  • 드래그 앤 드롭으로 목차/의안 순서 변경
  • 각 항목엔 풍부한 본문 (에디터 사용 가능)
  • 의안엔 의결 결과 (원안가결/수정가결/부결/보류) + 찬반 집계

출석부 · 위임장

의원 명단 등록 후 회의 당일 직접 출석 또는 위임장 등록. 정족수 카드는 실시간으로 충족/미달을 표시합니다.

회의 진행 모드

"📺 회의진행" 버튼 → 프레젠테이션 모드. 안건을 한 화면씩 큰 글씨로 표시하며 발표용으로 활용합니다.

회의록 출력

"🖨 회의록" 버튼으로 A4 회의록을 즉시 인쇄 가능. 안건 결과·출석부·조직도까지 자동으로 포함됩니다.

초대장

"💬 초대장" → 카카오톡/이메일로 보낼 수 있는 공유 링크 생성. 행사 타입의 경우 자유 신청 폼이 함께 노출되어, 신청자가 자동으로 출석부에 등록됩니다 (전화번호 중복 불가).

9커뮤니티 (게시판)

3가지 게시판 채널이 제공됩니다:

  • 📣 공지사항 — 관리자 작성, 상단 고정 가능, 본문은 에디터
  • 💬 자유게시판 — 회원 누구나 작성, 댓글 + 조회수
  • 🎉 회원소식 — 자유게시판과 분리된 채널

10정관

기관 정관(규정)을 위한 전용 페이지. 풀-페이지 WYSIWYG 에디터 + 버전 이력. 정식 발행 시 버전 저장하면 이후 비교·복원 가능합니다.

11조직도

드래그로 노드를 배치하고 자동 elbow 라인으로 연결하는 시각적 조직도 편집기. 여러 버전 보관, A4 미리보기/인쇄, JSON 내보내기/가져오기 지원.

주요 기능

  • 노드 추가 / 글상자 추가 / 노드 삭제
  • 마우스 드래그로 위치 이동, 자동 충돌 방지
  • 노드 색상(타이틀/내용 별도 지정), 메모 (호버 말풍선)
  • 되돌리기/다시하기 (10단계)
  • 자동 저장 (1.5초 디바운스) + 편집 종료 시 부모 페이지에 즉시 반영
💡

편집 종료 → 보기 모드: 편집 중 편집 종료를 누르면, 보류된 자동 저장이 끝날 때까지 부모 페이지가 잠시 대기 후 새 데이터를 다시 불러옵니다. "내보내기 누르고 나서야 반영되던" 이전 동작은 해결되었습니다.

12에디터 사용법

SmartMeet의 모든 본문(공지·게시글·일정·인사말·정관·의안·푸터)은 동일한 커스텀 리치 에디터를 사용합니다.

스마트 블록 (＋ 블록)

일반 에디터에서는 직접 만들기 어려운 패턴화된 콘텐츠를 한 번에 삽입합니다. 13종:

  • 🎯 스테이트먼트 — MISSION·VISION 강조 배너 (배경 6종)
  • 🌅 히어로 배너 — 인사말 그라디언트 헤더 (그라디언트 6종)
  • 🧩 피처 그리드 — 아이콘+제목+설명 (2~4열)
  • 📇 피처 카드 — 단일 강조 카드 + 상단 강조선 6종
  • 💡 정보 콜아웃 — 강조 정보 박스 (파랑)
  • ⚠️ 주의 콜아웃 — 경고 박스 (호박)
  • ✨ 팁 콜아웃 — 노하우 박스 (초록)
  • 📌 TL;DR 요약 — 글 시작 한 줄 요약
  • ⚖️ 2단 비교 — Before/After · 장단점
  • ✅ 체크리스트 — 체크박스 항목 묶음
  • ❝ 인용 + 출처 — 강조 인용문
  • 🖼️ 이미지 갤러리 — 3장 그리드 (2~4열 가변)
  • 🔘 CTA 버튼 — 클릭 유도 버튼 (Ctrl+클릭 = 링크 편집)

각 블록은 활성화 시 우측 상단에 떠 있는 ⚙️ 도구막대로 속성을 자유롭게 조정할 수 있고, 🗑️로 즉시 삭제 가능합니다.

13모바일 사용

모든 페이지가 모바일에 최적화되어 있습니다.

모바일 전용 동작

  • ☰ 햄버거 메뉴 — 사이드바가 화면 밖에서 슬라이드 인. 탭 외부 영역(백드롭) 또는 메뉴 항목 선택 시 자동 닫힘
  • 홈 상단 탭 — 햄버거 → 우측 드로어 → 아코디언 메뉴 (자식이 있는 항목은 ▾ 화살표, 탭 시 펼침)
  • 모달 = 시트 — 화면 하단에서 슬라이드 업, 풀너비, 상단 라운드
  • 입력 = 16px — iOS 자동 줌 방지
  • 캘린더 셀 탭 — 그 날짜의 일정 리스트 모달
  • 회의 페이지 — 정족수 → 회의요약 → 회의목차 순으로 자동 정렬
  • 푸터 — 로고 → 본문 → 편집 버튼 세로 정렬
  • 터치 타겟 — 버튼 최소 36px 높이

14시스템 관리자

admin@smartmeet.co.kr 같은 시스템 관리자 계정은 /admin에 접근하여 다음을 관리할 수 있습니다:

  • 사용자 관리 — 모든 사용자 검색·소속기관 변경·비밀번호 초기화·삭제
  • 기관 관리 — 모든 기관 진입·관리·정보 수정·회원수 클릭으로 사용자 목록 이동
  • DB 백업 — 운영 DB 스냅샷을 로컬로 다운로드 (점검·이관용)
  • 시스템 개요 — 사용자/기관 통계
⚠️

주의: 시스템 관리자는 모든 데이터에 접근 가능합니다. 자격을 부여할 때는 신뢰할 수 있는 운영진에게만 부여하세요. users.role = 'admin' 으로 식별됩니다.

15자주 묻는 질문

Q. 회원가입 인증 메일이 안 옵니다.

A. 스팸 메일함을 먼저 확인하세요. 1시간이 지나면 토큰이 만료되니 만료된 경우 다시 가입 요청을 진행해주세요. 시스템 관리자가 이메일 발송(Resend) 설정을 점검할 수 있습니다.

Q. 임원 명단의 텍스트가 드래그로 선택이 안 됩니다.

A. v1.0 업데이트로 행 전체가 아닌 좌측 ⋮⋮ 핸들에서만 드래그가 시작되도록 변경되었습니다. 이름·전화 등은 일반 텍스트처럼 자유롭게 선택·복사 가능합니다.

Q. 모바일에서 캘린더 일정이 셀을 넘어 깨져 보입니다.

A. 화면을 새로고침해주세요. 최신 빌드에서 grid blowout 문제가 수정되었습니다 (`minmax(0, 1fr)` 적용).

Q. 조직도를 편집한 후 보기 모드로 돌아가면 변경이 반영되지 않습니다.

A. v1.0에서 수정되었습니다. "편집 종료" 버튼이 자동 저장 완료를 기다린 후 보기 모드를 갱신합니다. 그래도 동기화가 안 되면 페이지를 새로고침해주세요.

Q. 전화번호 형식을 어떻게 통일하나요?

A. 입력 시 자동으로 010-1234-5678 형태로 변환되며, 서버에는 숫자만 저장되어 검색·중복 검출이 일관됩니다. 화면 표시는 다시 하이픈 형태로 보입니다.

Q. 초대코드는 어디서 만드나요?

A. 기관 관리자 사이드바 → 구성원 · 초대 → 초대 링크 발급. 만료일·사용 횟수 한도 설정 가능. 초대 링크 또는 토큰을 사용자에게 전달하면 자기 메뉴에서 직접 입력해 가입할 수 있습니다.
