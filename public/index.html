회의 운영의 모든 단계를 커버합니다

준비부터 진행, 기록까지 — 흩어져있던 작업을 하나로.

📋

의안 관리

리치 텍스트 에디터로 의안 본문·표·이미지 작성. 드래그앤드롭으로 순서 정렬.

✍️

전자 위임장

링크/QR 발급, 모바일 3단계 제출(의안 확인→본인 인증→전자서명).

✅

실시간 정족수

출석·위임 자동 합산, 정족수 충족 여부 즉시 시각화.

📺

프레젠테이션

표지·목차·의안 자동 슬라이드, 키보드 조작과 현장 의결 팝업.

🖨

회의록 출력

출력 항목 선택 후 Word(.doc) 다운로드. 한 번에 인쇄까지.

🔑

역할 기반 권한

시스템·기관 관리자·일반 회원 3단계 권한과 기관별 초대 링크.

이렇게 운영합니다

3단계로 회의 한 사이클이 끝납니다.

등록

기관 등록 → 회의 생성 → 의원 명단 등록

준비

의안 작성 → 위임장 링크 발송 → 출석·정족수 점검

진행 / 기록

프레젠테이션 + 현장 의결 → 회의록 자동 구성 → Word 출력
